# Notice: how Vista Platform Core is distributed after 5.2.1

Dated 2026-10-28. This notice does not change after it is published; a later
change gets a notice of its own.

## What changed

- **The platform's source code is no longer published.** Vista Platform Core
  5.2.1 (2026-10-27) was the last release published as source. The former
  public source repository receives no new releases and is being made private;
  once it is, everything in it, its release downloads included, stops being
  reachable.
- **Core is now distributed as signed images and a signed Helm chart**, with
  the release files and instructions in this repository. Core stays free.
- **The sensor and the device interrogation agent are open source** under the
  Apache License 2.0 in
  [VistaSecurity/VistaPlatform-Agents](https://github.com/VistaSecurity/VistaPlatform-Agents),
  which builds, signs and releases them.

## What this breaks

- **The download buttons of consoles from 5.2.1 and earlier** point at release
  files of the former public repository. Those files stop being downloadable
  when it becomes private, and the buttons then fail.
- **Links into the former repository** (its documentation, scan reports, release
  pages and raw files) stop working at the same moment.

There is no redirect, no migration window, and no republishing of earlier
releases or their agent binaries. This was decided on purpose, and nothing
will be added later to restore those links.

## What to do

- **Upgrade** to a release published here ([INSTALL.md](INSTALL.md)). The
  database schema upgrade from 5.2.0 and 5.2.1 is tested with every release;
  the rest of an upgrade across this change (images, chart, agents) was not
  rehearsed from a pre-change install: back up first, and if the upgrade does
  not succeed, install fresh.
- **Get agents through the console** of the new release (**Discovery →
  Sensors & Agents**), which offers exactly the agents release that platform
  version was tested with, or from the agents repository's release named in the
  release's `AGENTS.md`. Agents installed from a release before this change are
  not supported against later releases: replace them and enroll them again.
- **Report problems** in this repository's issue tracker, and vulnerabilities
  privately as [SECURITY.md](SECURITY.md) describes.

Releases up to and including 5.2.1 keep the licence they were published under
([TERMS.md](TERMS.md)); nothing here changes it.
