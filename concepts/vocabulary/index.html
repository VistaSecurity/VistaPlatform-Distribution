    Vocabulary¶

    Vista Platform uses one set of nouns for the objects it inventories, in the user interface, the API and these docs. Where an industry data model already has a name for a thing, Vista uses it. This page lists the terms.

    The NetBox column shows the object each term corresponds to when you exchange data with a NetBox instance. A dash means there is no counterpart.
